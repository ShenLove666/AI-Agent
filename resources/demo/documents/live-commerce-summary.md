# 直播购物争议：客服决策摘要

本文为项目原创摘要。通过直播销售商品仍应履行信息披露、质量、售后和承诺责任。客服应保留直播间、主播、实际经营者、商品链接和关键承诺；平台应建立消费者保护与争议解决机制，并按要求提供必要记录。直播口播若构成广告或具体服务承诺，不能在售后阶段简单认定为“主播个人表述”。

官方来源：[消费者权益保护法实施条例](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2024/art_0aea188276a44f0baf940ab95ee00e0a.html)。
