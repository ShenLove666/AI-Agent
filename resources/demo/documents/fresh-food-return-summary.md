# 鲜活易腐商品：无理由与质量问题分流

本文为项目原创摘要。鲜活易腐商品通常属于七日无理由退货的法定例外，但“不能无理由退货”不等于出现破损、腐败、温控异常或不符合约定时没有售后权利。客服必须先判断是主观不需要，还是质量、履约或描述不符；后者应进入质量售后流程。涉及食用安全时，不应给出“可以继续食用”的保证，应建议停止食用、保留凭证并升级处理。

官方来源：[网络购买商品七日无理由退货暂行办法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_26ca8fe29e184edd899fa0a7a060d935.html)。
