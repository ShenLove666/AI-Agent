# v2.1 状态一致性与检索范围

本轮针对上传契约、会话状态、失败恢复和 Retrieval Scope 做收敛，优先消除“界面可选但后端不可用”和“刷新后状态回退”。

## 上传契约

- 上传界面只展示后端真实支持的 TXT、Markdown、PDF、DOCX；
- Remote URL 与 Pipeline 入口暂时隐藏，打开上传弹窗不会请求未实现的 Pipeline 接口；
- 服务端在写入前校验扩展名，不支持格式返回 415；
- 服务端流式写入时执行 `MAX_UPLOAD_FILE_SIZE` 限制，超限返回 413 并删除不完整文件。

## 会话一致性

- Conversation 新增 `last_message_at`，每次写入消息都会更新；列表按最近消息时间排序；
- 首轮 SSE meta 返回真实标题，侧边栏不再等待刷新才改名；
- 同一 `requestId` 失败重试时，从 Prompt 历史排除原问题和失败的部分回答，当前问题只出现一次；
- 推荐追问持久化 `NOT_REQUESTED / GENERATING / SUCCESS / EMPTY / FAILED` 状态与错误；
- 失败生成保存真实 Assistant Message，并把 `messageId` 返回前端。

## 模型可靠性

同步和流式模型路由都会检查最终回答是否为空。HTTP 200 但没有最终正文会记为供应商失败，并在尚未向客户端输出内容时尝试下一个供应商；只有思考、没有最终答案也不会标记为成功。

## Retrieval Scope

聊天输入区提供知识库多选器：

```text
用户选择 KB IDs
  -> ChatRequest.knowledge_base_ids
  -> RetrievalRequest.knowledge_base_ids
  -> Keyword + Vector 两个通道共同过滤
```

空选择代表当前用户的全部知识库。现有 owner 条件仍始终生效，不能通过提交其他用户的知识库 ID 越权检索。

## 应用入口与依赖

- `app.main:app` 成为标准 ASGI 入口，`server.py` 同样指向该入口；
- API 与完整依赖文件直接声明 `openai` 和 `argon2-cffi`；
- 移除当前应用未使用的 LangChain 间接依赖。
