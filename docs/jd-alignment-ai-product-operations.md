# AI 产品运营实习生 JD 适配说明

本项目已从通用 RAG Demo 延展为“电商商家 AI 运营助手”，用可运行功能呈现产品运营、Agent 质量优化和数据洞察能力。

## 能力映射

| JD 关注点 | 项目产出 | 可演示路径 |
|---|---|---|
| 商家 AI 产品落地 | 商家账号活跃与工具渗透统计、知识库和提示词配置 | 管理台 → 商家运营洞察 / 知识库管理 / 智能体管理 |
| Agent 训练与质量优化 | 点赞点踩标注、质量评测漏斗、负反馈样本和优化建议 | 管理台 → 商家运营洞察 / 链路追踪 |
| 数据洞察与运营分析 | 好评率、反馈覆盖率、知识命中率、高频经营意图和问题率 | 管理台 → 商家运营洞察 |
| 问题排查与持续迭代 | RAG Trace、无知识、慢响应、失败运行诊断 | 管理台 → 商家运营洞察 → 链路追踪 |
| 可展示成果 | 可交互 Demo、真实数据 API、CSV 洞察报告、自动化测试 | `/admin/operations` 与测试目录 |

## 指标口径

- 工具渗透率：统计窗口内发起消息的账号数 / 全部注册账号数。
- 反馈覆盖率：收到点赞或点踩的 AI 回答数 / AI 回答总数。
- 回答好评率：点赞回答数 / 已反馈回答数。
- 知识命中率：有检索结果的已完成 Trace / 已完成 Trace。
- 高频意图：使用透明的电商关键词基线识别订单物流、售后服务、商品咨询、营销活动和门店经营；生产环境可替换为模型分类器。

无数据时所有指标显示 0，不使用伪造业务数字。当前“商家”以系统账号做代理口径，接入真实商家主数据后可按商家 ID、行业和城市进一步拆分。

## 面试 Demo 建议

1. 上传商品、活动、配送与售后规则到知识库。
2. 分别发起订单物流、退款、库存和满减活动问题。
3. 对部分回答点赞或点踩，打开链路追踪解释问题发生在哪个节点。
4. 在商家运营洞察页切换时间窗口，展示渗透、质量、意图分布与问题诊断。
5. 导出 CSV 报告，说明如何据此排知识补齐和 Agent 优化优先级。
